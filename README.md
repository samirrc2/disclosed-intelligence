# Disclosed Intelligence

Computational artifact for the article:

**Disclosed Intelligence: A Large-Sample Measurement of AI Disclosure in U.S. Investment Adviser Fiduciary Filings**

### Paper summary

Industry surveys report that a majority of registered investment advisers (RIAs) now use artificial intelligence (AI), yet what advisers commit to in their legally binding fiduciary disclosures has been unmeasured. From the SEC Form ADV Part 1 structured data (16,223 active SEC-registered advisers reporting regulatory AUM), the study draws a stratified random sample of 400 firms (adviser type × AUM quartile), retrieves each firm's current Form ADV Part 2A brochure from the Investment Adviser Public Disclosure (IAPD) system, and classifies each brochure with a five-label typology using a large language model.

**Main findings (all regenerated by this artifact):**

- **Disclosed AI use is low and steeply stratified:** 23.7% of brochures (95% CI 19.7–28.2) disclose any use, rising from about 9% among the smallest advisers to 30% (wealth/retail) and 56% (private-fund) among the largest; trend and adviser-type effects are both significant (logistic regression, p < 0.001).
- **A survey-weighted estimate** reweighting the strata to the brochure-filing population is 22.7% (95% CI 18.7–26.6), close to the design estimate.
- **The dominant disclosure mode is a risk warning** (27.6%), not a claim of use.
- **Independent cross-family validation** (180 blinded brochures re-coded by a different model family, metrics design-weighted to the population via two-phase verification sampling) gives any-use κ = 0.74 (precision 0.76, recall 0.84); the risk-factor label reaches κ = 0.93.
- **Potential AI-washing exposure is rare** in brochures (5 of 388, 1.3%; none an unsubstantiated promotional claim of the charged type on adjudication) and no larger in current marketing; firms disclose AI use more in the lawyered brochure (23.0%) than on their websites (5.7%).

This repository is the frozen dataset and deterministic analysis pipeline that regenerates those numerical results, tables, and figures.

### Role of the artifact

The artifact enables independent reproduction of the article's computational results. It provides:

1. The frozen, pseudonymized dataset (`data/`) — the sample, the primary and validation label sets, the population stratum counts, and the venue/exposure tables.
2. A deterministic analysis pipeline (`code/src/analyze.py`) that regenerates the typology prevalences with Wilson intervals, the size/type gradient with trend tests and a logistic regression, the survey-weighted estimates with design-based intervals, the independent cross-family validation metrics, the exposure screen, and the venue comparison — writing tables, figures, and a verdict-first `metrics_summary.md` under `results/`.
3. The frozen measurement instruments (`data/prompts/`) and the article PDFs (`paper/`).

**Default workflow:** regenerate all results from the frozen dataset. This path requires **no LLM API keys** and incurs **no inference cost or network access**. The upstream SEC retrieval and LLM classification are not re-run; their outputs are frozen (see `data/README.md`).

## 2. Reproduce

### On Code Ocean

Click **Reproducible Run**. The capsule executes `/code/run` → `bash code/scripts/reproduce.sh`, which analyzes the frozen data and then verifies that two independent runs produce byte-identical tables. Outputs appear under `/results` (`metrics_summary.md`, `tables/`, `figures/`).

### Locally

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r code/requirements.txt
bash reproduce.sh              # analyze + determinism check → results/latest/
bash reproduce.sh --analyze-only
bash reproduce.sh --test       # unit tests only (no data needed)
```

Expected headline output (`results/latest/metrics_summary.md`):

```
Disclosed any-use (design): 23.7% (95% CI 19.7-28.2); n=388
Survey-weighted any-use (brochure-filing): 22.7% (95% CI 18.7-26.6)
Independent cross-family validation (n=180, design-weighted): any-use κ=0.738, precision 0.761, recall 0.837
AI-washing exposure screen: 5/388 brochures (1.3%)
Venue comparison (n=283): brochure 23.0% vs marketing 5.7%
```

## 4. What is and is not reproduced here

**Reproduced (offline, deterministic):** every number, table, and figure in the article's results sections — prevalence, gradient, trend/logistic inference, survey weighting, validation, exposure, and venue comparison.

**Not re-run:** the SEC Form ADV download, the IAPD brochure retrieval, and the LLM classification. These require network access, API keys, and cost, and the raw brochure text is firm-identifiable. Their outputs are frozen in `data/`. The collection code that produced them is documented in `docs/DATA_PROVENANCE.md`.

**Pseudonymization:** firm identifiers are replaced by `fid` (`F0001`…`F0400`) per the article's Data Availability statement. All statistics are invariant to identity and reproduce exactly.
